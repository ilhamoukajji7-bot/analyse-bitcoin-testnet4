# analyse-bitcoin-testnet4

analyse du transaction bitcoin sur testnet 4
Analyse d'une transaction Bitcoin

Sujet

Analyse d'une transaction réalisée sur le réseau Bitcoin TestNet4.

Démarche

Étude des entrées, des sorties, des frais de transaction, des confirmations et des UTXO.

Résultat attendu

Comprendre le fonctionnement d'une transaction Bitcoin à partir d'un exemple réel.
